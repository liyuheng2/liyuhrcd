# TMC-HCRD-RIB 补充验证结果

完成 400 个主矩阵训练单元和 50 个 IEMOCAP 跨会话训练单元。
所有训练使用现有冻结特征和固定超参数。MOSI 为排除零分的二分类，CH-SIMS 为五分类，MELD 为七分类，IEMOCAP 为六分类。
使用本机 CPU 计时。实验协议和复现命令见 [TMC_EXTENDED.md](../../TMC_EXTENDED.md)。

## 跨会话与融合对照

IEMOCAP 五折属于冻结缓存上的探索性结果。DialogueGCN 的文本提取器使用情绪标签训练，缓存上游的训练划分未针对本实验各折重建。TMC 在会话 1–4 的准确率约为 89%–92%，会话 5 约为 52%。五折均值不宜作为严格的跨会话泛化证据。 [DialogueGCN 论文第 3.2 节](https://aclanthology.org/D19-1015/)

- IEMOCAP LOSO tmc 的折均准确率为 82.78%，折间标准差为 17.11 个百分点。
- IEMOCAP LOSO full 的折均准确率为 82.41%，折间标准差为 17.61 个百分点。
- CMU-MOSI 三模态干净测试中，冲突均分与责任分配的 NLL 分别为 0.4484 与 0.4482。
- CH-SIMS 三模态干净测试中，冲突均分与责任分配的 NLL 分别为 1.3190 与 1.3189。
- MELD 三模态干净测试中，冲突均分与责任分配的 NLL 分别为 1.5512 与 1.5502。
- IEMOCAP 三模态干净测试中，冲突均分与责任分配的 NLL 分别为 1.4366 与 1.4374。
